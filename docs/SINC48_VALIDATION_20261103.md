# 48kHz Sinc受信の検証

2026-11-03。48kHz同士の受信補間をSincへ切り替える試作。一般配布の承認は含まない。
線形補間の測定は [以前の記録](PCM_QUALITY_VALIDATION_20261103.md) に保持する。

## 実装と対象

プラグインの実装commitは `05bc632`。`AURALYN_SINC48_POC=ON` の専用DLLを使用する。
128tap・256分割位相の係数と作業領域はReaderの生成時に確保し、音声描画では確保・解放・待機を行わない。
共有メモリの読み取りに失敗しても進む出力clock、epoch・状態・tagの確認を維持する。
既定のビルドはOFF。48kHz以外の変換は既存の線形補間を使い、その音質改善を宣言しない。

本体は入力クロック補正の実装 `2e3d4a2` の専用実行ファイルを使用する。
入力補正は既定OFFのfeatureであり、この実機結果を通常版の採用と扱わない。

## 同じデジタル入力の比較

線形補間と同じ48kHz stereo f32・70秒を使い、100Hz/1kHz/10kHz/19kHzの4帯域を比較した。
速度差0/±37/±500ppmの全条件で、19kHzの帯域内power差の絶対値は0.0001dB未満。
以前の線形補間では、速度差のある条件で約3.9〜4.0dB減衰していた。
モデルの開始後underrun/overrun/invalid/staleはいずれも0。prefill・起動時のskipは別のcounterに記録する。

同じUSBマイク→OTTの参照録音70秒を+37ppmで処理したRMS差は+0.002401dB。
入力raw・出力raw・統計・SHA-256・PSD・音量を揃えた試聴WAVは `build/quality-final/` に保持する。
これは受信Readerのオフライン測定。共有メモリIPC、実時間負荷、全帯域の歪率・SNR、異なるrate間のalias除去、聴感の合格を表さない。
聴感確認は回答待ち。

## 実機の連続運転

USB 2.0 Camera → WASAPI 48kHz → OTT → 入力クロック補正ON → 共有メモリ → Sinc受信 → 隔離OBS 32.2.2。
物理モニターはミュート。通常OBSの設定保存領域は変更しない。
事前60秒試験は入力不足・転送エラーの増加0、波形比較3窓以上が成功した。

1時間試験 `build/native-20261103-051925/runs/clock-on-20261103-052730/` は、実時間3600.0秒で完了した。
解析12項目は全て成功。録音音声は172800000 frame・168750 packet・3600.0秒で、packet間の時刻欠損0。
入力の不足callback・ゼロ充填・破棄・滞留回復、受信のunderrun/overrun/invalid/staleは、録音中の増分が全て0。
reset・接続変更・lock取得失敗・出力clock再初期化の増分も0。起動後の累積counterに含まれる待機中の値とは分けて判定した。
OBS追加バッファ0ms、参照録音172801920 frame・取りこぼし0。21ファイルのSHA-256と通常OBS設定の保存内容も不変。
受信queueの標本値は44.0625〜56.0625ms。開始・中盤・終盤の8窓を同じデジタル参照と比較し、正規化相関の最小値は0.9990786。
queueの待ち量やファイル間の位置差は、物理的な総遅延の実測値ではない。

## 操作・配布の確認

新DLLの `scenarios-20261103-062826/` は録音66.4107秒、15区間全てが成功した。
global/VSTのmute、singing/talkの無音保持と復帰、Stop/Start、所有する送信側の強制終了と再起動、42機器の1回スキャンを確認。
録音packetの時刻欠損・OBS追加バッファ0、物理出力peak 0、通常OBS設定の内容も不変。
無音判定は操作後500msを除く2秒窓で行い、制御要求の成功だけで無音成立としない。瞬時の無音化時間を保証する測定ではない。
ローカル配布候補にはSinc headerと実機で確認した補間方式を含め、異なる方式・DLL・ソースの証拠を受理しない。
一般配布、対応ソース一式、通常OBSへの導入、署名の残件は [配布準備](DISTRIBUTION_READINESS.md) に残す。
ASIO経路、映像との同期、利用者の試聴は未確認。

## 自動確認と限界

Sinc ON/OFFの各ビルドでCTest 2件が成功。Python 20件も成功した。
render中の確保0、最大2048 frameと±2000ppmの境界、有限な最大振幅、履歴tag不一致の無音化を含む。
これらの単体・モデル試験は実機1時間の代わりにはせず、双方の証拠を保持する。
今回の一構成・48kHzの成立を、全デバイス・全rate・聴感の受入へ広げない。
